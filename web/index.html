Instruction Fields

x86 instructions are made of named fields. Some fields are optional — if a field is not needed, the instruction simply omits it, which is why instructions can be different lengths.

What is variable-length vs fixed-length?

The number of bytes an instruction uses is called its length. Different CPU designs make different choices about this. Click the bars below to compare.

Inside a RISC-V instruction — fixed fields, always 32 bits

Every field always sits at the same bit position in every instruction of this type. The CPU does not need to scan the instruction to find them.
